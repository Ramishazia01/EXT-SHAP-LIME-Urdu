# EXT-SHAP-LIME-XAI

This repository contains RTL (Right-to-Left) explainability tools for Urdu, Arabic, and other RTL languages using **SHAP** and **LIME**.

## Contents

- **SHAP_RTL/** — SHAP-based explainability and RTL visualization.
- **LIME_RTL/** — LIME-based explainability for RTL text.

## Purpose

The project provides tools for generating and visualizing explainable AI (XAI) results for RTL languages while preserving correct text direction and rendering.
